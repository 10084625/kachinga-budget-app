# Kachinga – Personal Budgeting App

Android app

## About

Budgeting app to record income and expenses by category, attach receipt photos, set monthly minimum and maximum spending goals with alerts, and track savings goals with a forecast of when each goal will be reached.

Includes a calendar view, category spending reports and achievement badges to keep users motivated.

## Built with

- Kotlin
- Jetpack Compose
- MVVM
- Room database

## Getting started

1. Open the project folder in Android Studio.
2. Let Gradle sync finish.
3. Run the app on an emulator or Android device.
